# SuiShield

See what a Sui transaction does before you sign it.

SuiShield simulates transactions against live chain state and shows you exactly what leaves your wallet, what arrives, and whether anything looks wrong — so you never blind-sign again.

### Features (in development)

- **Transaction preview** — asset changes, object transfers, and contract calls in plain language
- **Risk detection** — drainer patterns, unusual outflows, unverified contracts
- **Phishing warnings** — known scam sites flagged before you connect
- **No backend** — everything runs client-side against public Sui RPC

Web app and browser extension coming soon.
